# Surface brief — app/pages/index.vue (seluruh UI overlay)

## Direction contract

**THESIS:** Overlay kaca yang berdiri tenang di depan dunia 3D yang hidup — UI tidak menyaingi ruang klinik, ia "mengapung" di atasnya; menolak tampilan putih-papan-tulis ala laman simulator generik.

**OWN-WORLD:** Kaca gelap (#0D1420 @ 50–72% + blur 10–14px, border putih 10–12%), teks putih #F2F6FD, sekunder slate; violet #8B5CF6 eksklusif untuk aksi/brand/aktif; emerald = lulus, rose = gagal/timer kritis, amber = peringatan; radius 12–16px, shadow lembut beroffset. Sora untuk heading, JetBrains Mono untuk seluruh angka mengukur (timer, skor, nomor stasiun).

**STORY:** Peserta langsung paham alurnya di layar sambutan (pilih mode → masuk), lalu selama bermain API-nya tim: stasiun giliran Siapa/Sekarang, waktu tersisa, progres 10 stasiun — semua terbaca <2 detik tanpa menutupi pandangan 3D.

**FIRST VIEWPORT:** Welcome = panel kaca 440px di tengah: chip brand + titik status hijau atas, Sora 30px dua baris, paragraf 2 kalimat, segmented control 2 mode, CTA violet penuh dengan ikon Play, hint kbd di kaki panel. Latar: gradasi gelap atas-bawah membingkai koridor 3D. CTA adalah satu-satunya elemen solid berwarna.

**FORM:** Arah dipilih user melalui wawancara terstruktur (Klinik Glass Dark; diluar lemparan seed). seed: none (unavailable).

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
